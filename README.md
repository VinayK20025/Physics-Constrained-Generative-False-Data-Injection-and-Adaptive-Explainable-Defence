# Physics-Constrained Generative False Data Injection Attacks and Adaptive Explainable Defence for Water Distribution Systems

## Overview
This repository accompanies the research paper:

**Physics Constrained Generative False Data Injection Attacks and Adaptive Explainable Defence for Water Distribution Systems Using a Multi Network Closed Loop Digital Twin**
The project presents a reproducible cyber-physical security framework for evaluating stealthy False Data Injection (FDI) attacks against Water Distribution Systems (WDSs). The framework integrates physics-constrained generative models with a closed-loop digital twin to assess attack realism, physical impact, and anomaly detection performance.

## Features
- Physics-constrained generative FDI attack generation
- WGAN-GP, TimeGAN, and Conditional GAN attack models
- Closed-loop WNTR/EPANET digital twin simulation
- Multi-network benchmarking using public EPANET datasets
- Statistical, machine learning, deep learning, graph-based, and reinforcement learning anomaly detection
- Explainable AI using SHAP, LIME, attention visualization, and counterfactual analysis
- Reproducible experimental pipeline


## Datasets
Experiments use publicly available EPANET benchmark water distribution networks.
Repository:
https://github.com/KIOS-Research/epanet-function-test

Simulation is performed using:
- EPANET
- WNTR (Water Network Tool for Resilience)
